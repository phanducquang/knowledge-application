# Web Agent Instructions

Before any UI change, read these repository-level documents in order:

1. `../../docs/DESIGN.md`
2. `../../docs/REFERENCE_SCREENS.md`
3. `../../docs/AI_CODING_GUIDELINES.md`

The current Knowledge List page is the first reference implementation of the visual language. Reuse its typography, spacing, neutral palette, dividers, sidebar density, control radius and responsive behavior rather than inventing a new visual system.

Do not introduce a generic `Card` component unless a future semantic use case explicitly requires a contained surface.
