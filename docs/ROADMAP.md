# Roadmap

This roadmap represents the current direction, not a release commitment.

## Phase 0 — Foundation

- monorepo structure
- architecture documentation
- design constitution
- AI coding guidelines
- reference screen definitions

## Phase 1 — Core knowledge MVP

- initialize Next.js application
- initialize Spring Boot application
- authentication
- knowledge CRUD
- Markdown editor/rendering
- tags
- PostgreSQL persistence
- PostgreSQL Full Text Search
- Private/Public visibility
- public slug page

## Phase 2 — Sharing and authoring quality

- Unlisted visibility/share token
- attachments/images via R2 or MinIO
- revision history
- collections
- table of contents
- syntax highlighting
- Mermaid

## Phase 3 — Knowledge relationships

- backlinks
- wiki links
- related articles
- knowledge graph

## Phase 4 — AI-assisted retrieval

- pgvector
- embeddings
- semantic search
- Ask My Knowledge
- source-linked answers
- auto tagging/summarization
